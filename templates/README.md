# templates/

Pasta reservada para a fase de conversão HubSpot (HubL), compartilhada
entre todas as instituições (o tema HubSpot final serve `UAM/`, `UNIFACS/`
etc. a partir de um único Design Manager).

Enquanto as páginas estão em construção/aprovação como HTML/CSS/JS puro
(ver `<INSTITUICAO>/pages/`, `<INSTITUICAO>/modules/` e
`<INSTITUICAO>/public/`, ex.: `UAM/pages/`), este diretório fica vazio.
Quando uma página for aprovada visualmente, ela é portada para cá
seguindo a estrutura de tema do HubSpot (`theme.json`, `fields.json`,
`templates/layouts/base.html`, `modules/<secao>.module/...`), uma seção
por módulo, exatamente como hoje organizado em `<INSTITUICAO>/modules/sections/`
— ver `AGENTS.md` na raiz do projeto para o fluxo completo.
