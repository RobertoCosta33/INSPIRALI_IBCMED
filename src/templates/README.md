# templates/

Pasta reservada para a fase de conversão HubSpot (HubL).

Enquanto as páginas estão em construção/aprovação como HTML/CSS/JS puro
(ver `pages/`, `src/` e `public/`), este diretório fica vazio. Quando uma
página for aprovada visualmente, ela é portada para cá seguindo a
estrutura de tema do HubSpot (`theme.json`, `fields.json`,
`templates/layouts/base.html`, `modules/<secao>.module/...`), uma seção
por módulo, exatamente como hoje organizado em `src/` — ver `AGENTS.md`
na raiz do projeto para o fluxo completo.
