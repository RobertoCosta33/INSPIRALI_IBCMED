# UNA/src/templates/ — Tema HubSpot (IBCMED - UNA)

Reservado para a conversão da página estática (`UNA/src/pages/index.html` +
`UNA/src/modules/`) para um tema HubSpot CMS (HubL), seguindo exatamente o
mesmo padrão já aplicado em `UAM/src/templates/` (ver esse README para a
estrutura completa de referência).

Enquanto a página UNA estiver em construção/aprovação como HTML/CSS/JS puro
em `UNA/src/modules/` + `UNA/src/pages/index.html`, esta pasta fica vazia.
Quando o visual for aprovado, cada seção de `UNA/src/modules/sections/`
(e os módulos compartilhados de `UNA/src/modules/shared/`) vira um módulo
HubL (`<secao>.module/`) aqui dentro, 1:1 com a contraparte da UAM.
